*L’idée derrière tout ça:*
Pour les anciens, composer = *faire voyager l’auditeur*.
- *La tonalité* = un pays
- *La modulation* = changer de pays
- *La mesure/compasso* = la boussole pour ne pas se perdre
- *Le tempo* = la vitesse du voyage: Andante = à pied, Presto = en TGV

*Ma préférée: Portamento*
Mot-à-mot: "porter".
En musique c’est quand la note "porte" le son jusqu’à la suivante. Comme si la mélodie faisait du stop 😄
